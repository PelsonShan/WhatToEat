# “吃什么”小程序设计文档

日期：2026-08-31
状态：已与用户确认

## 1. 背景与目标

为家人日常“吃什么”做决定而设计一款微信小程序。核心价值是：把家里常吃的菜和常去的馆子记下来，到饭点随机抽一组，解决选择困难；周末或晚间还能触发“超级大奖”，带家人出去吃。

目标用户为家人内部使用，不公开发布，不需要复杂登录和运营体系。

## 2. 范围

### 本期包含

- 四个底部 Tab：今日签、食单、觅食、膳记
- 今日签：灶下组合随机、超级大奖（市井）、人在外面时的附近随机
- 食单：灶下菜品库 + 市井馆子库，手动录入 + 热门菜品一键导入
- 觅食：附近好味、四方风味（菜系探索）、尝新推荐
- 膳记：家人身份信息、最近吃过记录
- 微信云开发：云数据库 + 云函数，家人账号共享数据
- 防重复算法：按确认记录降权，默认全家维度
- 中国风视觉：中国红 + 鎏金 + 米黄纸，晓式祥云、印章、抽签

### 本期不做

- 公开上架、商用发布
- 多人实时协作、投票、转盘房间
- 支付、外卖下单、点评系统
- 口味、忌口、预算等偏好设置（菜品库天然只收录家人接受的菜）
- 复杂权限与多家庭隔离

## 4. 功能设计

### 4.1 今日签

首页顶部标题为“今日签”，页面包含两种使用模式。

#### 在家模式（灶下）

- 组合选择：一菜一汤 / 两菜一汤 / 三菜一汤 / 自由单点
- 候选范围：食单中“灶下”分类的菜品
- 菜品分类：主菜、汤、主食；按组合自动搭配，组合内不重复
- 流程：选择组合 -> 转盘随机 -> 结果签文 -> 换一批 / 确认
- 换一批不记录；确认后写入膳录，参与防重复
- 候选不足：自动放宽防重复并提示；无汤候选时只出菜并提示可去热门导入

#### 超级大奖（市井）

- 时间窗：
  - 周一 00:00 - 周五 17:00：不触发
  - 周五 17:00 后及周末：按当前时段概率触发
- 触发概率：
  - 午餐 11:00-14:00：15%
  - 晚餐 17:00-21:00：40%
  - 其他时段：25%
- 触发后从食单“市井”随机一家馆子，展示名称、地址、备注、距当前位置距离
- 操作：换一家 / 确认就去这家 / 打开导航
- 防重复同样生效：最近确认去过的馆子降权
- 市井为空：提示先到“觅食 - 附近好味”收藏，或这次先在家吃

#### 在外面吃模式

- 用户选择“我就在外面”后授权定位
- 腾讯位置服务按当前位置搜索周边馆子（默认 5 公里内）
- 随机一组 3 家候选，展示名称、类型、距离、评分
- 收藏过的市井馆子若在结果中优先排进候选
- 操作：换一组 / 选这家 / 导航；确认后记录并参与防重复

### 4.2 食单

- 顶部搜索“寻味...”
- 两类切换：灶下 / 市井
- 灶下菜品字段：名称、分类（主菜/汤/主食）、菜系、常吃标记、来源（手动/热门导入）
- 市井馆子字段：名称、地址、坐标、常去标记、备注
- 支持新增、编辑、删除；热门菜品一键导入
- 数据全家共享、云端同步

### 4.3 觅食

- 附近好味：腾讯位置服务 POI 搜索，显示距离与类型，可一键收藏进市井
- 四方风味：内置热门菜品按菜系浏览，可一键加入灶下
- 尝新推荐：从热门菜品中推荐“未加入食单且最近没吃过”的菜

### 4.4 膳记

- 当前用户信息：微信头像、昵称、家人称呼（如爸爸）
- 家人列表：印章头像展示（如爸、妈、仔）
- 膳录：最近吃过/去过的记录，含组合、馆子、时间、确认人
- 页面底部古风落款：一粥一饭 · 当思来处

## 5. 视觉规范

- 主色：中国红 #9f1d16 / #b3261e
- 辅色：鎏金 #d9a441 / #f2c14e
- 纸色：米黄 #f8ecd0，卡片 #fff7e0
- 文字：墨棕 #5a241d / #6b4a35 / #8a5a3b
- 字体：宋体/楷体（Songti SC、STSong、KaiTi、STKaiti、SimSun）
- 祥云：采用“晓”式云朵图形（圆润云身 + 卷尾），头部用米金色，纸面用淡红色水印
- 印章：今日签、上上签、常吃、家宴等采用印章样式
- 随机结果：转盘“今日卦” + 签文卡“上上签”，菜品用标签换行展示
- 底部 Tab：今日签 / 食单 / 觅食 / 膳记

## 6. 技术架构

### 6.1 技术选型

- 原生微信小程序（WXML/WXSS/JS）
- 微信云开发：云数据库 + 云函数
- 腾讯位置服务：周边馆子 POI 搜索、距离计算、导航跳转

### 6.2 数据模型

云数据库集合：

- `users`：openid、昵称、头像、家人称呼、创建时间
- `dishes`：名称、分类（主菜/汤/主食）、菜系、常吃、来源（手动/热门导入）、添加人、创建时间
- `restaurants`：名称、地址、坐标、常去、备注、添加人、创建时间
- `hot_dishes`：内置热门菜品，只读，供四方风味浏览与一键导入
- `pick_history`：类型（在家/大奖/外面）、组合、菜品或馆子、确认人、时间

### 6.3 云函数

- `login`：获取/登记用户身份，返回 openid 与用户信息
- `randomPick`：按组合与防重复算法返回候选；区分在家、大奖、外面模式

### 6.4 防重复算法

- 权重规则：
  - 24 小时内确认过：权重 0
  - 24 小时 - 3 天：权重 20%
  - 3 - 7 天：权重 50%
  - 7 天以上：权重 100%
- 默认按全家记录防重复（一家人通常一起吃）
- 换一批不写记录，只影响候选；确认才写膳录
- 同一次随机组合内不重复；换一批之间尽量不重复
- 候选不足时逐级放宽：先允许 3 天内，再全部放回并提示

## 7. 容错与边界

- 定位拒绝或失败：提示开启定位，附近好味不可用时其余功能不受影响
- 腾讯位置服务异常或配额用尽：附近好味显示轻量提示，不阻塞其他功能
- 网络/云服务异常：提示稍后重试，列表读取缓存最近一次数据
- 多人同时编辑：以最后一次写入为准，MVP 不做冲突处理

## 8. 测试与验收

- 算法单测：用 Node 覆盖组合抽选、防重复权重、时间窗概率、候选不足放宽、汤缺失
- 手动测试：微信开发者工具模拟器 + 真机预览，验证多账号共享
- 验收清单：
  - 四个 Tab 导航与命名
  - 今日签：组合选择、随机、换一批、确认
  - 超级大奖时间窗与概率
  - 在外面吃：定位、3 家候选、换一组、选这家、导航
  - 食单：新增、编辑、删除、热门导入、寻味搜索
  - 觅食：附近好味收藏、四方风味导入、尝新推荐
  - 膳记：家人信息、最近吃过记录
  - 多账号防重复
- 上线前检查：云开发环境初始化、腾讯位置服务 key 配置、真机定位授权
